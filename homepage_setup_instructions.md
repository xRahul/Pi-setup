# Homepage Widget Setup Instructions

Your dashboard is configured from the live directory pointed to by `HOMEPAGE_CONFIG_PATH` in `.env`. In the current stack that path is `/home/rahul/docker_data/gethomepage`, mounted into the Homepage container at `/app/config`.

Use `HOMEPAGE_VAR_*` values from `.env` for widget credentials. Do not hardcode API keys or passwords directly in Homepage YAML.

## How to Edit
1. Open the configuration file:
   ```bash
   nano /home/rahul/docker_data/gethomepage/services.yaml
   ```
2. Scroll to the service you want to enable.
3. Uncomment the `widget:` block (remove `#` from the start of the lines).
4. Replace the placeholders (e.g., `<API_KEY>`) with your actual credentials.
5. Save and exit (`Ctrl+O`, `Enter`, `Ctrl+X`).
6. Restart Homepage to apply:
   ```bash
   docker compose restart homepage
   ```

## Caddy Widget Note

Caddy admin is intentionally bound to `localhost:2019` for safety. Homepage runs in a separate container, so it should not use the Caddy admin widget against `10.8.1.48:2019`. Use `siteMonitor` for Caddy availability instead, for example:

```yaml
siteMonitor: http://10.8.1.48:80
```

## Service-Specific Instructions

### 1. Immich (Photo Backup)
*   **Feature:** Displays photo/video count and storage usage.
*   **Get Key:** 
    1. Log in to your Immich Web UI (`https://immich.pi.rahulja.in`).
    2. Go to **Account Settings** (User Icon) -> **API Keys**.
    3. Click **Create API Key**.
    4. Give it a name (e.g., "Homepage") and ensure **"Server Statistics"** permission is checked.
    5. Copy the generated key.
*   **Config:**
    ```yaml
    widget:
        type: immich
        url: http://10.8.1.6:2283
        key: YOUR_GENERATED_API_KEY
        version: 2
    ```

### 2. Paperless-ngx (Documents)
*   **Feature:** Displays document counts (inbox, total, issues).
*   **Get Token:**
    1. Log in to Paperless-ngx (`https://pngx.pi.rahulja.in`).
    2. Go to **My Profile** or **Django Admin** -> **Auth Tokens**.
    3. Alternatively, you can just use your Username and Password directly.
*   **Config:**
    ```yaml
    widget:
        type: paperlessngx
        url: http://10.8.1.32:8000
        key: YOUR_API_TOKEN  # OR remove 'key' and use 'username' and 'password'
    ```

### 3. Tailscale (VPN)
*   **Feature:** Displays connection status and device count.
*   **Get IDs:**
    1. **Device ID:** Go to [Tailscale Machines](https://login.tailscale.com/admin/machines), click on your Raspberry Pi machine. The ID is at the bottom of the details pane (e.g., `node:123...` or just the ID).
    2. **API Key:** Go to **Settings** -> **Keys** -> **Generate Access Token**.
*   **Config:**
    ```yaml
    widget:
        type: tailscale
        deviceid: YOUR_DEVICE_ID
        key: YOUR_ACCESS_TOKEN
    ```

### 4. Filebrowser (Files)
*   **Feature:** Displays disk usage/file stats.
*   **Config:**
    ```yaml
    widget:
        type: filebrowser
        url: http://10.8.1.34:80
        username: admin  # Your Filebrowser username
        password: password # Your Filebrowser password
    ```

### 5. Pi-hole (DNS)
*   **Status:** *Currently configured with your web password.*
*   **Troubleshooting:** If the widget shows an error, you might need the explicit API Token.
    1. Log in to Pi-hole (`https://pihole.pi.rahulja.in/admin`).
    2. Go to **Settings** -> **API / Web Interface**.
    3. Click **Show API Token**.
    4. Update the `key` field in `services.yaml`.

### 6. Stirling-PDF (PDF Tools)
*   **Feature:** Status and version info.
*   **Config:**
    ```yaml
    widget:
        type: stirlingpdf
        url: http://10.8.1.58:8080
    ```
